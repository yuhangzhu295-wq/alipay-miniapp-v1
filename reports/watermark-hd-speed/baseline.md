# 高清去水印生产基线

在任何算法或配置修改前，通过生产域名连续执行了 5 次真实 LaMa 高清请求。使用生产留存的用户发票结果图作为同尺寸纹理样本（上传原图按现有隐私策略不落盘），尺寸 `1495×999`、947401 字节；用两个相距较远的小笔迹复现当前统一外接矩形问题。

| 指标 | P50 | P95/最大 |
| --- | ---: | ---: |
| 端到端 | 20005.4ms | 23230.7ms |
| Backend | 19145ms | 21832ms |
| LaMa | 18815ms | 19140ms |
| 队列等待 | 0ms | 0ms |

两处小遮罩被构造成一个 `1422×935` ROI，占原图 `88.5226%`。LaMa 占服务端耗时约 94% 至 98%，上传连接、队列、输出合成都不是主因。对照组单个 `335×210` 小 ROI 的生产 P50 为 2107.3ms，LaMa P50 为 1219ms。

5 次均满足 `engine=lama`、`fallbackUsed=false`、`lamaCallCount=1`、输出 `1495×999`、ROI 外改变像素 `0`。
