---

## 2. Logic Chain

1. From **Observation 1** and **Observation 2**, we establish that a FastAPI backend instance is running on port 8000 under PID `39008` spawned via `uvicorn main:app --port 8000`.
2. From **Observation 3**, we trace the presence of all primary, secondary, and fallback models and verify they are fully downloaded and present on the disk (their file sizes correspond to standard model distributions).
3. From **Observation 4**, **Observation 5**, **Observation 6**, and **Observation 7**, we map out the complete temporary and cache directory footprint of the application. The Hivision engine creates a temporary runtime folder under `idphoto_hivision_ascii` to avoid path issues, and python's temporary image cutout saves `tmp*.png/jpg` directly into the system temp dir. The cumulative size of these directories is ~3.21 GB, containing over 16,000 files.
4. Based on this, a comprehensive cleaning script (using safe paths and file filters) must be run by the implementer during Milestone 1.

---

## 3. Caveats

- We assumed that all `tmp*.png` and `tmp*.jpg` files in the user's system temp directory `C:\Users\zyu33\AppData\Local\Temp\` are generated by this application's matting engine fallback or compost functions. If other apps on the machine use similar patterns, they might also be removed by a blanket delete, although `tmp*` files are by definition transient and safe to delete.
- We did not investigate browser/WeChat DevTools cache since that is client-side.

---

## 4. Conclusion

The port 8000 process is active and running the main backend server (PID 39008). The system has accumulated ~3.21 GB of cached images and logs that can be safely reclaimed. All weight models are fully present in their designated locations.

## 5. Verification Method

- **Verify process audit**:
  Run `cmd /c "netstat -ano | findstr :8000"`. If PID 39008 is listed, the process is active.
- **Verify weights presence**:
  Check paths from **Observation 3** to verify they exist and match the sizes.
- **Verify cache sizes**:
  Run `cmd /c "dir /s C:\Users\zyu33\AppData\Local\Temp\idphoto_hivision_ascii\runtime"` to inspect files.
