# Analysis Report — Frontend Layout Download Option Feature

This report outlines the analysis and design recommendations for implementing the frontend layout download option feature in the ID Photo Generator application.

## 1. Backend API Analysis (`server/main.py`)

### Observations
- In the `/api/id-photo/compose` endpoint (defined around lines 1458–1581), a layout image path is processed if generated by the underlying core:
  ```python
  layout_url = ""
  if "layoutPath" in result and result["layoutPath"]:
      with open(result["layoutPath"], "rb") as f:
          layout_bytes = f.read()
      _remove_temp_file(result.get("layoutPath"))
      layout_saved = save_output_with_meta(
          layout_bytes,
          ".jpg",
          ...
      )
      layout_url = layout_saved["urlWithVersion"]
  ```
- The endpoint correctly generates the layout and registers it. However, the final returned dictionary of `id_photo_compose` (lines 1548–1581) does not contain the key `"layoutUrl"`.
- Conversely, `/api/id-photo/generate-v2` does correctly return `"layoutUrl": layout_url` in its response dictionary (line 1278).

### Recommendation
Add `"layoutUrl": layout_url` into the returned response JSON dictionary inside `id_photo_compose` in `server/main.py`:
```python
        return {
            "success": True,
            "imageUrl": image_url,
            "finalImageUrl": image_url,
            "resultUrl": image_url,
            "previewUrl": image_url,
            "downloadUrl": image_url,
            "layoutUrl": layout_url,  # Add this line
            "outputUrl": saved["url"],
            ...
```

## 2. API Utility Class Analysis (`utils/aiImageApi.js`)

### Observations
- `aiImageApi.js` provides client wrappers `generateIdPhotoV2` and `composeIdPhotoV2` for communicating with the backend.
- In `generateIdPhotoV2` (lines 260–275), the success callback resolves the Promise but ignores `data.layoutUrl`.
- In `composeIdPhotoV2` (lines 395–437), the success callback does not extract or normalize `data.layoutUrl` for the resolved output.

### Recommendation
Update both functions to extract, normalize, and return `layoutUrl`:

1. **In `generateIdPhotoV2`**:
   ```javascript
   if (data.success && (data.finalImageUrl || data.resultUrl || data.imageUrl)) {
     var imageUrl = data.finalImageUrl || data.resultUrl || data.imageUrl;
     var fullUrl = _normalizeResultUrl(imageUrl);
     var layoutUrl = data.layoutUrl ? _normalizeResultUrl(data.layoutUrl) : '';
     resolve({
       tempFilePath: fullUrl,
       resultPath: fullUrl,
       finalImageUrl: fullUrl,
       remoteUrl: fullUrl,
       layoutUrl: layoutUrl, // Extract and normalize layoutUrl
       mode: data.mode || options.mode || 'official',
       ...
   ```

2. **In `composeIdPhotoV2`**:
   ```javascript
   if (data.success && (data.finalImageUrl || data.resultUrl || data.imageUrl)) {
     var requestId = data.requestId || (data.debug && data.debug.requestId) || '';
     var cacheBust = data.cacheBust || (data.debug && data.debug.cacheBust) || requestId || Date.now();
     var imageUrl = _withCacheBust(data.previewUrl || data.finalImageUrl || data.resultUrl || data.imageUrl, requestId, cacheBust);
     var fullUrl = _normalizeResultUrl(imageUrl);
     var downloadUrl = _normalizeResultUrl(_withCacheBust(data.downloadUrl || imageUrl, requestId, cacheBust));
     
     // Extract and normalize layoutUrl
     var layoutUrl = data.layoutUrl ? _normalizeResultUrl(_withCacheBust(data.layoutUrl, requestId, cacheBust)) : '';
     
     var previewFilePath = data.previewFilePath || (data.debug && data.debug.previewFilePath) || '';
     ...
     _downloadResult(imageUrl).then(function(localPath) {
       resolve({
         tempFilePath: localPath,
         resultPath: localPath,
         finalImageUrl: fullUrl,
         previewUrl: fullUrl,
         downloadUrl: downloadUrl,
         layoutUrl: layoutUrl, // Add layoutUrl here
         previewFilePath: previewFilePath,
         ...
   ```

## 3. Generate Page Analysis (`pages/generate/generate.js` & `pages/generate/generate.wxml`)

### Observations
- In `generate.js`, `generatePhoto` handles calling the backend.
- Currently, when `composeIdPhotoV2` resolves, the page stores the single image but doesn't keep track of any remote layout image.
- When saving, `savePhoto()` (lines 580–674) retrieves the image path (which might be the locally rendered canvas layout or the single photo) and invokes `wx.saveImageToPhotosAlbum` or downloads it first if it's a remote URL starting with `http`.

### Recommendation

1. **Store layoutUrl in Page Data**:
   In `generatePhoto`'s success callback, store `result.layoutUrl` in `this.setData`:
   ```javascript
   that.setData({
     generating: false,
     processState: 'ready',
     statusText: requestBgColorName + ' · 可下载',
     resultImage: result.tempFilePath,
     resultPreviewSrc: result.previewUrl || result.finalImageUrl || result.remoteUrl || result.tempFilePath,
     resultRemoteUrl: result.finalImageUrl || result.remoteUrl || '',
     layoutUrl: result.layoutUrl || '', // Store backend layoutUrl
     resultColorId: requestBgColorId,
     layoutColorId: '',
     canDownload: true
   }, function() {
     if (that.data.outputTab === 'layout') {
       if (result.layoutUrl) {
         that.setData({
           layoutImage: result.layoutUrl,
           layoutColorId: requestBgColorId
         });
       } else {
         that.generateLayoutPhoto();
       }
     }
   });
   ```

2. **Update `setOutputTab`**:
   Ensure switching to the layout tab utilizes `layoutUrl` if available:
   ```javascript
     setOutputTab: function(e) {
       var tab = e.currentTarget.dataset.tab;
       var that = this;
       this.setData({ outputTab: tab }, function() {
         if (tab === 'layout' && that.data.resultImage && !that.data.layoutImage) {
           if (that.data.layoutUrl) {
             that.setData({
               layoutImage: that.data.layoutUrl,
               layoutColorId: that.data.resultColorId
             });
           } else {
             that.generateLayoutPhoto();
           }
         }
       });
     },
   ```

3. **ActionSheet Download Logic in `savePhoto()`**:
   Modify `savePhoto` to show a action sheet when `layoutUrl` exists:
   ```javascript
     savePhoto: function() {
       var that = this;
       if (!that.data.canDownload) {
         wx.showToast({ title: '请先生成可下载的证件照', icon: 'none' });
         return;
       }

       var downloadAndSave = function(src, isLayout) {
         var doSave = function(filePath) {
           wx.saveImageToPhotosAlbum({
             filePath: filePath,
             success: function() {
               wx.showToast({ title: '已保存到相册', icon: 'success' });
               var createdAt = Date.now();
               var record = {
                 id: 'photo_' + createdAt,
                 imagePath: filePath,
                 imageUrl: isLayout ? '' : that.data.resultRemoteUrl,
                 remoteUrl: isLayout ? (that.data.layoutUrl || '') : that.data.resultRemoteUrl,
                 specId: that.data.currentSpecId,
                 specName: that.data.specName,
                 sizeText: that.data.specSize,
                 bgColorName: that.data.bgColorName,
                 backgroundColor: that.data.bgColorName,
                 widthPx: that.data.currentSpec ? (that.data.currentSpec.widthPx || 0) : 0,
                 heightPx: that.data.currentSpec ? (that.data.currentSpec.heightPx || 0) : 0,
                 type: isLayout ? 'layout' : 'idPhoto',
                 createdAt: createdAt,
                 expireAt: createdAt + 24 * 3600 * 1000
               };
               var list = wx.getStorageSync('myPhotos') || [];
               list.unshift(record);
               wx.setStorageSync('myPhotos', list);
               imageService.savePhotoRecord(record);
             },
             fail: function(err) {
               if (err.errMsg.indexOf('auth') !== -1 || err.errMsg.indexOf('deny') !== -1) {
                 wx.showModal({
                   title: '需要权限',
                   content: '请在设置中开启保存到相册权限',
                   success: function(res) { if (res.confirm) wx.openSetting(); }
                 });
               } else {
                 wx.showToast({ title: '保存失败，请重试', icon: 'none' });
               }
             }
           });
         };

         if (src.indexOf('http') === 0) {
           wx.showLoading({ title: '准备下载...' });
           wx.downloadFile({
             url: src,
             timeout: 60000,
             success: function(res) {
               wx.hideLoading();
               if (res.statusCode === 200 && res.tempFilePath) {
                 doSave(res.tempFilePath);
               } else {
                 wx.showToast({ title: '下载失败，请重试', icon: 'none' });
               }
             },
             fail: function(err) {
               wx.hideLoading();
               console.error('[generate] download before save failed:', err);
               wx.showToast({ title: '下载失败，请重试', icon: 'none' });
             }
           });
         } else {
           doSave(src);
         }
       };

       if (that.data.layoutUrl) {
         wx.showActionSheet({
           itemList: ['下载单张照片', '下载六寸排版照'],
           success: function(res) {
             if (res.tapIndex === 0) {
               downloadAndSave(that.data.resultImage, false);
             } else if (res.tapIndex === 1) {
               downloadAndSave(that.data.layoutUrl, true);
             }
           },
           fail: function(res) {
             console.log('ActionSheet cancelled:', res.errMsg);
           }
         });
         return;
       }

       // Standard fallback behavior if layoutUrl is not present
       var saveSrc = that.data.outputTab === 'layout' ? that.data.layoutImage : that.data.resultImage;
       if (that.data.outputTab !== 'layout' && that.data.resultColorId !== that.data.bgColorId) {
         wx.showToast({ title: '请先生成当前底色证件照', icon: 'none' });
         that.generatePhoto();
         return;
       }
       if (that.data.outputTab === 'layout' && that.data.layoutColorId !== that.data.bgColorId) {
         that.generateLayoutPhoto();
         wx.showToast({ title: '正在生成当前底色排版照', icon: 'none' });
         return;
       }
       if (that.data.outputTab === 'layout' && !saveSrc && that.data.resultImage) {
         that.generateLayoutPhoto();
         wx.showToast({ title: '正在生成排版照', icon: 'none' });
         return;
       }
       if (!saveSrc) {
         wx.showToast({ title: '请先生成证件照', icon: 'none' });
         return;
       }
       downloadAndSave(saveSrc, that.data.outputTab === 'layout');
     }
   ```

## 4. Result Page Analysis (`pages/result/result.js` & `pages/result/result.wxml`)

### Observations
- `pages/result/result` is currently not registered in `app.json`. However, to make it fully compatible with the new backend layout download flow, we should still configure it to handle `layoutUrl`.
- In `onLoad()`, the page receives initial values, but ignores `layoutUrl`.
- In `selectLayout()`, when selecting the `4x2` layout mode, it generates the layout using local canvas code: `imageUtil.generateLayoutPhoto(userPhoto, spec, cols, rows)`.
- In `savePhoto()`, it tries to directly call `imageUtil.saveImageToAlbum(path)` without checking if it needs to download it first. If `previewSrc` is set to a remote URL, `saveImageToAlbum` (which calls `wx.saveImageToPhotosAlbum`) will fail.

### Recommendation

1. **Receive and Store `layoutUrl`**:
   In `onLoad()`, fetch `layoutUrl` from options or global storage:
   ```javascript
     onLoad(options) {
       const app = getApp();
       ...
       const layoutUrl = (options && options.layoutUrl) || app.globalData.layoutUrl || '';
       this.setData({
         photoSrc: userPhoto,
         layoutUrl, // Save in page data
         ...
   ```

2. **Update `selectLayout()`**:
   If the user selects the `4x2` layout mode, and a backend `layoutUrl` is available, display it directly:
   ```javascript
     selectLayout(e) {
       const layoutId = e.currentTarget.dataset.layout;
       this.setData({ selectedLayout: layoutId });

       if (layoutId === 'single') {
         this.setData({ showPreview: false, previewSrc: null });
         return;
       }

       if (layoutId === '4x2' && this.data.layoutUrl) {
         this.setData({ showPreview: true, previewSrc: this.data.layoutUrl });
         return;
       }

       // Otherwise, fallback to generating locally:
       const app = getApp();
       const spec = app.globalData.selectedSpec || specs.getSpecById('1inch_normal');
       const userPhoto = app.globalData.generatedPhoto || app.globalData.userPhoto;
       const [cols, rows] = layoutId.split('x').map(Number);
       ...
   ```

3. **Clear `layoutUrl` on modification**:
   If the user triggers `changeColor` or `changeSpec`, they are editing the photo locally using local canvas helper methods. The old `layoutUrl` generated by the backend is no longer synchronized with their edits.
   Clear `layoutUrl` inside both methods:
   ```javascript
   this.setData({
     layoutUrl: '',
     ...
   ```

4. **Update `savePhoto`**:
   Verify if the path is a remote URL starting with `http` or `https`. If so, download it before saving:
   ```javascript
     savePhoto() {
       const path = this.data.previewSrc || this.data.photoSrc;
       if (!path) {
         wx.showToast({ title: '没有可保存的照片', icon: 'none' });
         return;
       }

       const doSave = (localPath) => {
         wx.showLoading({ title: '保存中...' });
         imageUtil.saveImageToAlbum(localPath)
           .then(() => wx.hideLoading())
           .catch(() => wx.hideLoading());
       };

       if (path.indexOf('http') === 0) {
         wx.showLoading({ title: '下载中...' });
         wx.downloadFile({
           url: path,
           success: (res) => {
             wx.hideLoading();
             if (res.statusCode === 200 && res.tempFilePath) {
               doSave(res.tempFilePath);
             } else {
               wx.showToast({ title: '下载失败，请重试', icon: 'none' });
             }
           },
           fail: (err) => {
             wx.hideLoading();
             wx.showToast({ title: '下载失败，请重试', icon: 'none' });
           }
         });
       } else {
         doSave(path);
       }
     }
   ```

## 5. Test Verification Analysis (`server/scripts/verify_frontend_ui.py`)

### Observations
- The test verifier executes frontend page JavaScript inside a Node.js harness, utilizing mocked versions of `wx` API and other helper modules.
- Currently, `wx.showActionSheet` is not mocked. If the frontend code calls it, it will crash with a `TypeError`.
- The mocked `composeIdPhotoV2` does not return `layoutUrl` in its resolved promise.

### Recommendation

1. **Mock `wx.showActionSheet`**:
   Add the following mock function to the `global.wx` object inside the `HARNESS` script in `server/scripts/verify_frontend_ui.py`:
   ```javascript
     showActionSheet(opts) {
       wxCalls.push({ fn: 'showActionSheet', opts });
       if (opts && opts.success) {
         // Mock selecting '下载六寸排版照'
         opts.success({ tapIndex: 1 });
       }
     },
   ```

2. **Add Mock `layoutUrl` in API Mock Responses**:
   Update `composeIdPhotoV2` and `generateIdPhotoV2` in `HARNESS` (inside `Module._load` override) to include a mock layout URL:
   ```javascript
         composeIdPhotoV2: (payload) => Promise.resolve({
           success: true,
           tempFilePath: 'tmp://final-' + (payload.bgColorName || 'blue') + '.jpg',
           finalImageUrl: 'http://127.0.0.1:8000/outputs/final.jpg',
           layoutUrl: 'http://127.0.0.1:8000/outputs/layout.jpg', // Add mock layoutUrl
           quality: { qualityReport: { passed: true, score: 99 } },
   ```

3. **Add Test Assertions**:
   Include a new UI check verifying the ActionSheet layout option flow:
