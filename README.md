# 📷 证件照生成器 (全能版) - 微信小程序

一款基于大语言模型与前沿 AI 计算机视觉技术打造的**全能图像处理工具**微信小程序。采用前后端分离架构，前端使用原生微信小程序开发，后端基于 FastAPI 提供高性能推理能力。

## ✨ 核心功能

- **📸 智能证件照制作**：
  - **双引擎极致抠图**：支持 Hivision 高低配双轨路由，极速模式（秒出图）与发丝精修模式（`birefnet-v1-lite` + `modnet` 双重穿透）。
  - **多规格内置**：内置 12+ 种标准规格（一寸、二寸、身份证、各类签证等），并支持自定义尺寸。
  - **一键换底色**：白、蓝、红、浅蓝、灰，精准色彩边缘过渡。
  - **精美排版照**：支持 4×2、8×1 标准打印排版输出。
- **🧹 AI 图片去水印**：基于 IOPaint/Lama 等先进图像修复模型，智能识别并无痕擦除照片上的杂物和水印。
- **📦 图片无损压缩**：本地极速算法，支持用户自定义压缩强度，轻松满足各种系统对文件大小的苛刻要求。
- **👔 正装换装 (开发中)**：一键为半身照匹配海量真实感西服、衬衫。

## 🛠️ 后端架构与技术要点

- **后端引擎**：Python 3.10+ & **FastAPI**，支持高并发异步处理。
- **AI 抠图矩阵**：深度整合开源抠图算法并引入智能降级回退机制，确保在 4C8G 服务器（纯 CPU 环境）下也能实现稳定极速响应。
- **前沿部署策略**：采用 PM2/Systemd 进程守护与 Nginx 反向代理 HTTPS 部署。

## 🚀 部署指导

1. **后端启动**：
   ```bash
   cd server
   pip install -r requirements.txt
   python main.py
   ```
2. **前端配置**：
   在 `utils/apiConfig.js` 中将 `PROD_API_BASE_URL` 指向您配置好的云服务器后端 HTTPS 域名。
3. **微信后台**：
   在微信公众平台配置 `request合法域名`，上传代码后提交审核即可发布。
