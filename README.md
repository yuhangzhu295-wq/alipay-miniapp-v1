# 📷 证件照生成器 - 微信小程序

一款功能完整的证件照制作微信小程序，用户可拍照或上传照片，选择规格和底色，一键生成符合标准的电子证件照。

## ✨ 功能特性

- **📸 拍照/上传**：支持拍照和从相册选择照片
- **📐 多规格选择**：内置一寸、二寸、身份证、各国签证等 12+ 种标准规格
- **🎨 底色切换**：支持白、蓝、红、浅蓝、灰 5 种底色
- **🖼️ 智能处理**：自动裁剪构图，背景替换
- **📋 排版打印**：支持 4×2、8×1 排版照生成
- **💾 保存分享**：一键保存到相册

## 📱 页面结构

```
pages/
├── index/        # 首页 - 拍照/上传 + 规格/底色选择 + 生成
├── result/       # 结果页 - 预览 + 换底色/尺寸 + 排版 + 保存
└── specs/        # 规格页 - 全部规格浏览 + 搜索
utils/
├── specs.js      # 证件照规格数据和底色数据
└── image.js      # 图片处理工具（生成、替换、排版、保存）
```

## 🛠️ 技术要点

- 使用 **Canvas 2D API** 进行图片合成处理
- **色度键替换** 技术实现简单背景替换
- 支持 **自定义规格** 扩展
- 符合 **300dpi** 打印标准的像素尺寸计算
- 前端本地处理，无需服务端支持

## 🚀 使用方法

1. 在微信开发者工具中导入本项目
2. 修改 `project.config.json` 中的 `appid` 为你的小程序 AppID
3. 预览/真机调试
